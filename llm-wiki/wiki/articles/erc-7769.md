# ERC-7769 JSON-RPC API for ERC-4337

## TL;DR

ERC-7769はWallet clientとERC-4337 Bundler間のJSON-RPCを定義するDraftである。送信、gas見積もり、receipt取得、対応EntryPoint照会を標準化する。

## Key claims

- `eth_sendUserOperation`はsimulationとmempool受理に成功した場合だけ`userOpHash`を返す。
- `eth_estimateUserOperationGas`はvalidationとexecutionのgas limitを返す。
- `eth_getUserOperationReceipt`の`success`とreceiptでオンチェーン実行結果を確認できる。
- Clientは送信先EntryPointがBundlerの対応一覧に含まれることを確認できる。

## Technical details

- 数値fieldはhex、空のbytes fieldは`0x`で送る。
- 送信時はUserOperationとEntryPoint addressをBundlerへ渡す。
- receiptには`userOpHash`、sender、nonce、実行成否、gas、logs、bundle transaction receiptが含まれる。
- validation、署名、paymaster、opcode ruleなどの失敗に分類済みerror codeがある。

## Limitations and caveats

- 2026-09-04時点でDraftであり、RPC fieldやerror仕様は変更され得る。
- Bundler実装ごとの対応EntryPoint versionと追加RPCを前提にしない。
- debug RPCはローカル開発専用とし、productionへ公開しない。

## Project relevance

- Phase 3 clientはProof取得後にUserOperationを構築し、このRPC境界でBundlerへ送る。
- E2Eは`userOpHash`受理だけでなくreceiptの成功と受取人残高変化まで確認する。
- [[erc-4337-zk-policy-payment]]のBundler境界を裏付ける。
