# Noir Installation

## Preserved material

- Noir公式ドキュメントはNargoの導入方法としてnoirupを案内している。
- noirupはnightly、特定version、branch、fork、PR、commit、local sourceを指定できる。
- Phase 1では特定versionの導入方法を使い、Nargo `1.0.0-beta.26`を固定した。

```bash
curl -L https://raw.githubusercontent.com/noir-lang/noirup/main/install | bash
noirup --version 1.0.0-beta.26
```
