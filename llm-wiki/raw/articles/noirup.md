# noirup

## Preserved material

- noirupはNargo toolchainを導入・切り替える公式installerである。
- `--version`、`--branch`、`--repo`、`--pr`、`-C`、`--path`で取得元を選択できる。
- GitHub Action integrationはearly developmentとされ、tag pinが推奨されている。
- Phase 1では`--version 1.0.0-beta.26`を使った。
