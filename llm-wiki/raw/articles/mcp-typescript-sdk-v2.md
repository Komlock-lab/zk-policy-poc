# MCP TypeScript SDK v2

## Preserved material

- `@modelcontextprotocol/server` v2は2026-07-28 MCP specificationのstable実装である。
- `McpServer.registerTool`とZod schemaでToolの入力契約を定義できる。
- `serveStdio`はlocal processとして起動されるServerへstdio transportを提供する。
- 同じServerを複数のMCP Hostから利用できる。
